# 221 Fallen Leaf Drive — finished social reel

- [Download the final 1080×1920 MP4](https://github.com/pittsga-stack/VideoEditing/raw/refs/heads/main/221-fallen-leaf-reel.mp4)
- [Download the editable project ZIP](https://github.com/pittsga-stack/VideoEditing/raw/refs/heads/main/reel-project.zip)

The reel runs approximately 71.5 seconds and uses H.264 video at 30 fps with AAC stereo audio. It removes the glitchy opening walk and trailing CapCut end card, tightens the tour, adds short dissolves and subtle portrait push-ins, and includes the address and price reduction text. Landscape footage retains its full width on a navy canvas; portrait footage fills the vertical frame.

The ZIP contains the FFmpeg rendering script, editable timing/text configuration, fonts, and instructions. To re-render, supply the original MOV as `source.mov` alongside the extracted files; the original footage is not included in this repository.
